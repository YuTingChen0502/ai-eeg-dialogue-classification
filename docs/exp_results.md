## Important Branch/File Note

Many branches generate files named simply `submission.csv`. That file name is **not reliable by itself** because switching branches or rerunning experiments can overwrite it. For Kaggle upload, prefer named files whenever available:

* Task 1: `task1_submission_*.csv`
* Task 2 EEG: `submission_task2_*.csv`
* Part 2 dialogue: `submission_bert_threshold.csv`, `submission_bert.csv`, `submission_classical_best_single.csv`, etc.

If only `submission.csv` exists for a branch, copy it immediately to a clearly named file outside the repo or under an ignored local upload folder before switching branches.
